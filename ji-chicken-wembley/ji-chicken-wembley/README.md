# JI Chicken Wembley — Concept Redesign

A single-page concept redesign for JI Chicken's Wembley branch, built as a night-market-inspired
alternative to the current site. Not affiliated with or endorsed by JI Chicken — fan-made project.

## What's here
- `index.html` — the whole site (HTML/CSS/JS in one file, no build step, no dependencies besides Google Fonts)

## Design direction
- **Palette**: warm ink black background, chili red + turmeric gold neon accents, a touch of scallion green
- **Type**: Anton (display, night-market signage energy) + Inter (body) + IBM Plex Mono (prices, labels, data)
- **Signature element**: an interactive "flavour wall" — 12 tappable seasoning-powder tiles with heat-level indicators,
  reflecting JI Chicken's real buffet bar of seasoning powders

## Run it locally
Just open `index.html` in a browser — no build tools required.

## Push to your own GitHub
```bash

```

## Content notes
Menu items, flavour names/descriptions, and copy are illustrative — written from research into JI Chicken's
public menu and brand story, not scraped verbatim from any source. Swap in real prices/photos before using this live.
